#Tic-Tac-Toe Game

A Tic Tac Toe game built using HTML, CSS, and JavaScript that lets two players take turns marking X and O on a 3x3 grid. It includes win/draw detection, interactive UI, and a reset option. This project is great for practicing logic building, event handling, and dynamic DOM updates in web development.
